# projeto-lista

## Descrição
Projeto direcionado a matéria de 'Projetos'. Nosso projeto conta com a expectativa de proporcionar uma lista de apoio para estudantes de escolas e faculdades, 

## Objetivos
- Proporcionar maior organização diária para quem usa o aplicativo;
- Praticar os ensinamentos realizados em sala de aula;
